# 直流电机速度环辨识指南

从"采样率 + PWM 输出 + 编码器输出"三样数据建立电机数学模型：

$$G(s) = K \cdot \frac{e^{-t_d s}}{\tau s + 1} \quad [\text{rpm}/\%\text{PWM}]$$

得到 **3 个参数**：静态增益 `K`、机械时间常数 `τ`、纯滞后 `t_d`（附 95% 置信区间）。

---

## 1. 实验条件（数据可信的前提）

| 项 | 要求 | 原因 |
|---|---|---|
| **车轮悬空** | 车轮离地，车体固定牢靠 | 触地会引入滚动阻力/路面波动等非线性负载，破坏一阶模型假设且不可重复 |
| **装上车轮** | 装实际使用的车轮及联轴件 | 车轮惯量是 `J` 的重要部分，拆掉会使 τ 偏小 |
| **预热** | 空转 1–2 分钟再采数据 | 轴承摩擦稳定后再辨识 |
| **供电稳定** | 稳压电源或满电电池，记录电压 | K 与供电电压成正比 |
| **开环** | 固定 PWM 给定，无闭环调节器参与 | 闭环数据需要用间接辨识方法，开环最可靠 |
| **安全** | 高速旋转，注意防护 | — |

## 2. 采集参数

- **采样率 500 Hz**（T_s = 2 ms）：相对电机带宽（约 3 Hz）超出 100 倍以上；
  纯滞后的辨识分辨率为 2 ms。
- **编码器 1024 线 ×4 倍频 = 4096 counts/rev，无减速**。
  换算：`rpm = counts/s ÷ 68.267`，即 1 count/采样 = 7.32 rpm。
- **幅值约束**：脉冲期间转速保持 **≥ 200 rpm**（此时量化噪声 ≤ 2%）；
  低于 100 rpm 的数据只用于确定基线与死区。

## 3. 激励序列（`simforge.id.excitation.DEFAULT_SEQUENCE`）

```
静止 1s → +20% 阶跃 4s → 静止 1s → +50% 阶跃 4s → 静止 1s → -50% 阶跃 4s → 静止 1s
   (训练)                  (留出验证)                 (训练，验证对称性)
```

- 每段脉冲 ≥ 4 s（≈80τ），稳态充分建立；
- **留出整段不参与辨识**，作为 out-of-sample 验证；
- 正负脉冲检查对称性/摩擦；可选 PRBS 段（`excitation.prbs()`）拓宽频域激励。
- 阶跃沿必须在 1 个采样周期内完成跳变。

## 4. CSV 数据格式

```csv
# fs: 500
# counts_per_rev: 4096
# supply_V: 12
# load: wheel_suspended
t_s,pwm_pct,enc_delta
0.000000,0.0,0
0.002000,0.0,0
```

- `enc_delta` = 该采样周期内累计的脉冲数（速度量，counts/采样）；
- 元数据行以 `#` 开头，`fs` 和 `counts_per_rev` 必填；
- 可选元数据：`ref_k`（理论 K，用于验收第 8 项）、`source_note` 等；
- 仿真的 `true_*` 参数仅用于算法自检，真实数据不需要。

## 5. 使用方法

```bash
# 0) 没有数据时：生成仿真数据跑通全流程（已知真值可自检）
python examples/simulate_motor.py

# 1) 真实数据辨识 + 生成报告
python examples/motor_speed_id.py --input data/your_run.csv --holdout 50

# 2) 单元测试（12 项，含端到端参数恢复回归）
python -m pytest tests -q
```

Python API：

```python
from simforge.id import load_motor_csv, run_identification, write_report

data = load_motor_csv("data/your_run.csv")
res = run_identification(data, holdout_duty=50.0)
print(res.arx.K, res.arx.tau, res.arx.td)   # K [rpm/%], tau [s], td [s]
write_report(res, "output/run1")
```

## 6. 方法说明

| 方法 | 原理 | 角色 |
|---|---|---|
| **ARX(1,1) + 延迟搜索** | `v[k+1] = a·v[k] + b·u[k-d]` 线性最小二乘，AIC 选延迟；`K=b/(1-a)`，`τ=-T_s/ln a` | **主方法**，给出置信区间 |
| **速度域输出误差 PEM** | 非线性最小二乘拟合 `v_model(K,τ,td)`，留出段不参与残差 | **交叉验证** |

> 注：原方案计划在累计计数（位置）上拟合以规避微分噪声，实测发现**过程扰动经积分后形成随机游走**，
> 会主导计数域残差并把 3 参数优化器"带偏"（拟合漂移而非动力学）。
> 在 ≥200 rpm 工作区间量化噪声仅 ±3.7 rpm，直接在速度域拟合既简单又一致，故采用速度域 PEM。

频域验证：Welch 方法估计实测频响 `H(f)=S_vu/S_uu`（带相干性），与模型伯德图对比。

## 7. 验收清单（`report.html` 自动输出）

1. 训练段 VAF ≥ 95%
2. 留出段 VAF ≥ 90%（整段未参与辨识）
3. 留出段稳态误差 ≤ 3%
4. Ljung-Box 白噪声检验 p > 0.05
5. 残差×输入互相关在 95% 置信带内
6. 双方法 K/τ 差异 ≤ 5%
7. ARX 参数 95%CI 相对宽度 ≤ 20%
8. K 与物理理论值偏差 ≤ 15%（理论值：`K ≈ 空载转速 / 空载占空比`，或元数据 `ref_k`）
9. 参数恢复误差 ≤ 2%（仅仿真数据，可对照真值）
10. **金标准复测**：换一个未用过的占空比录 5 s 阶跃，模型预测误差 ≤ 5%

1–7 项自动判定；第 10 项需人工做一次复测，是模型验收的最终裁判。

## 8. 模型有效范围（诚实声明）

- 模型是**特定工况下的局部线化**：悬空装轮、当时供电电压、脉冲转速区间；
- 换负载或电压后：`K ∝ 供电电压`，`τ ∝ 负载惯量`（τ 与负载转矩本身无关）；
- 触地运行时 K 会因电枢电阻压降略降，该偏差属于负载扰动，由闭环调节器消除；
- 速度低于 100 rpm 时量化与死区非线性显著，模型不保证该区间精度。
